# Calculadora em Java

Calculadora de linha de comando com menu interativo.

## Funcionalidades
- Soma, subtração, multiplicação, divisão, potência, resto e raiz quadrada
- Validação de entrada (aceita vírgula ou ponto decimal)
- Tratamento de erros com exceções (divisão por zero, raiz de número negativo)
- Histórico dos cálculos da sessão

## Como executar
```
javac Calculadora.java
java Calculadora
```
Requer JDK 11 ou superior.

## Tecnologias
Java, métodos estáticos, `Scanner`, `ArrayList` e tratamento de exceções.
