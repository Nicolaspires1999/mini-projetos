# Calculadora em Python

Calculadora de linha de comando com menu interativo.

## Funcionalidades
- Soma, subtração, multiplicação, divisão, potência, resto e raiz quadrada
- Validação de entrada (aceita vírgula ou ponto decimal)
- Tratamento de erros (divisão por zero, raiz de número negativo)
- Histórico dos cálculos da sessão

## Como executar
```
python calculadora.py
```
Requer Python 3.8 ou superior.

## Tecnologias
Python 3, funções, dicionários, tratamento de exceções e módulo `math`.
