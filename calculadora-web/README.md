# Calculadora Web

Calculadora feita com **HTML, CSS e JavaScript puro**, sem bibliotecas e sem `eval()`.

## Funcionalidades
- Soma, subtração, multiplicação e divisão
- Porcentagem, inverter sinal, apagar e limpar
- Tratamento de divisão por zero
- Correção de arredondamento (0,1 + 0,2 = 0,3)
- Suporte ao teclado (números, operadores, Enter, Backspace, Esc)
- Layout responsivo com tema claro e escuro automático

## Como usar
Abra o arquivo `index.html` no navegador.

## Tecnologias
HTML5, CSS3 (Grid, variáveis CSS) e JavaScript (DOM e eventos).
